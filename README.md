# Pokèsnap 🔴🔵

**Complete History of Every Pokémon Event, Card & More**

Welcome to Pokèsnap, a comprehensive database and archive of Pokémon history covering events, trading cards, games, and more!

## Features

✨ **Interactive Database**
- Browse complete history of Pokémon events since 1996
- View trading card set information and rarity
- Explore every mainline game release
- Real-time statistics about the Pokémon franchise

🔍 **Search Functionality**
- Search across events, cards, and games
- Find information about specific Pokémon products and releases
- Filter by keywords, dates, and types

📊 **Statistics**
- Total documented events
- Card sets catalogued
- Games released
- Years of franchise history

🎨 **Modern Design**
- Responsive design for mobile and desktop
- Beautiful gradient UI with smooth animations
- Easy-to-navigate interface
- Interactive cards with hover effects

## Content Included

### 📅 Events
- Game releases (Generations I-IX)
- Trading Card Game launches
- Anime and movie releases
- Major franchise milestones
- 17+ documented events

### 🃏 Trading Cards
- Classic Base Set through modern sets
- Set information and release years
- Notable and valuable cards
- Card rarity classifications
- 15+ major sets documented

### 🎮 Games
- All mainline Pokémon games
- Generation information
- Region details
- Platform information
- New Pokémon counts per generation
- 22+ games documented

## How to Use

1. **Browse Categories**: Scroll through Events, Trading Cards, and Games sections
2. **Search**: Use the search bar to find specific Pokémon products or events
3. **Learn**: Click on cards to see detailed information about each item
4. **Explore**: Check the statistics to see the scope of Pokémon history

## Database Structure

### Events Object
- ID, Name, Date, Location
- Description, Type, Impact Level

### Cards Object
- ID, Set Name, Year, Country
- Description, Rarity, Notable Cards

### Games Object
- Name, Release Year, Generation
- Region, Platforms, New Pokémon Count
